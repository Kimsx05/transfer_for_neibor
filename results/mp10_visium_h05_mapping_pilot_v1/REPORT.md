# 普通 Visium 四片 H05 映射与冻结 MP10 比较

**结论。** B17 的原始支持度与 MP10 最一致，但很大部分伴随 Epi 含量和测序深度变化。T1 的弱正相关在调整后保留，在移除 Top20 后接近零。B1 效应弱，BC01 的条件支持度与 MP10 呈弱负相关。H05 映射可以帮助定位参考谱系支持与原评分不一致的位置；目前证据不足以用它判定 H05 阳性 spot 或定量其细胞含量。

实际结果目录为 `/home/data/t070721/codex_workspace/Bladder Metabolism/results/mp10_visium_h05_mapping_pilot_v1`。四片全片共 12,979 spots，冻结 query 共 8,187。表达、旧评分、坐标和新预测逐键一一匹配，原始 UMI 列和与旧 nCount_RNA 的最大差均为 0。

- **B1。** 原始支持度的全片最大值仅 0.112。支持度随 Epi fraction 变化（r = 0.722），但 MP10 与该比例的片内相关约为 0.007，调整后原始支持度的相关略升。把 Epi 分母纳入解释后，仅见很弱的一致性。

- **B17。** 原始支持度与 Epi fraction 的 r = 0.827，与 log 深度的 r = 0.451。原始支持度与 Epi_support 几乎同步（r = 0.994）。即使限定在同一批 1,203 个分母非零的点，MP10 对原始和条件支持度的 r 仍分别为 0.223、0.043。69 个条件支持度 ≥ 0.9 的 query 中，68 个处于低分母区。

- **T1。** 92.8% 的 query 具有 Epi_support > 0.99，全部 query 均超过低分母界限。这里原始与条件读数较接近，组成和深度调整对结果影响小。原评分有 39.5% 为零，仍保留在散点与统计中。

## 全片非上皮位置

预定诊断区使用 c2l Epi fraction < 0.10 且其他大类占优。B1 无符合点；补查原 0.25 门槛以下且非 Epi 占优的 38 点，H05 支持度全部为零，中位 COL1A1 为 25 UMI、EPCAM 为 1。B17 的 452 个预定诊断点全部为零，以 Mural 为主（311 点）。BC01 的 2,439 点中位数为 0、Q95 为 0.012、最大值为 0.260，高尾见于 T/NK 占优位置。T1 仅 36 点，中位数为 0、最大值达 0.316；COL1A1 与 KRT8 的中位数分别为 126 与 9 UMI，可见混合组织信号。低 Epi 丰度可用于谱系定位检查，无法充当胆固醇生物学的绝对阴性真值。

## 如何使用这一层

保留原 mixed-spot MP10 作为主读数。标签映射增加了两类信息：一个 spot 的表达整体更支持哪类参考谱系，以及该谱系支持中有多少相对偏向冻结 high 状态。这两层在 B17 的分离揭示了组成混淆，在 T1 的接近说明该片主要需要关注定义基因共享。两种方法共享 RNA；逐片相关和消融衡量方法一致性。

**扩展判断。** 现阶段适用于这四片的描述性定位、筛查不一致区域及回看组织。片间异质性、低分母、深度效应和真零伪 spot 的较高支持度共同限制了阳性判定。暂不建议把该流程作为 H05 分类或定量工具铺开到 63 片。
