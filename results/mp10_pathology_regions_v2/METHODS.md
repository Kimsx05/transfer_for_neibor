# BLCA Visium computational tissue annotation v2

This analysis uses the frozen 63-section manifest and all 265,002 existing expression/tissue-QC positions, including positions below the old epithelial fraction gate. It does not rerun cell2location, MP10 scoring or communication analysis. Region identity, interface position and evidence/review status are separate outputs. These are computational annotations, not pathologist-confirmed diagnoses.

## Inputs and software

Original integer counts are read from the existing CopyKAT input MTX files with their original gene and barcode files. They are not integrated/Harmony/scaled expression. Coordinates and H&E paths reuse the aligned frozen input manifest. Existing cell2location **posterior mean abundance**, normalized by the sum of the 30 types within each spot, supplies composition; the q05 source is retained in the manifest but not mixed with mean. `major_map.tsv` defines non-overlapping major lineages. Full native CopyKAT CNA profiles in NPZ format were actually read for all 63 sections. Original native predictions, including `c1:diploid:low.conf`, are preserved.

R 4.5.3 loads the task-local Rlib, then the existing project R libraries (4.5, 4.4, /refdir/Rlib). SpaCET 1.4.0 and Banksy 1.9.5 were installed in the isolated task library. Per-section session information is saved. No existing environment was upgraded. Jobs are section-wise, with bounded internal workers and BLAS/OpenMP threads fixed to one; After the user requested lower memory usage, full-cohort concurrency was reduced from four to **two sections**, with subsequent sections using at most **six internal workers** each; the original 48 CPU / 200 GB ceiling still applies. The two interrupted sections were retried. After the user subsequently authorized four-section concurrency again, the queue returned to **four sections while retaining at most six internal workers per section**; running sections were adopted without restarting.

## SpaCET

The public `SpaCET.deconvolution(..., cancerType="BLCA", signatureType=NULL, adjacentNormal=FALSE)` entry point runs on raw counts. Its complete hierarchical deconvolution is retained. The algorithm requires at least 100 detected genes; excluded positions remain in the output with a status. Original barcode ↔ array-row-x-array-column mapping is saved explicitly. The estimated malignant component is a proportion, **not a probability that a spot is malignant**. Actual `malRes$sig` and the compact malignant inference results are saved, including CNA/expr/PANCAN/seq_depth fallback sources. `seq_depth` alone is not accepted as tumor evidence.

The major-component maximum compares Malignant, the major lineages named in the reference lineage tree, and Unidentifiable. Subtypes are not mixed into that comparison. Native `SpaCET.identify.interface(MalignantCutoff=0.5)` is run and saved unchanged. Its Interface is mainly the immediately adjacent non-tumor side. Its Stroma is an algorithmic non-tumor label and is not synonymous with histological stroma. Native classification is a comparison, not the final project mask. An isolated non-tumor position can receive an anomalous native Interface label in the public implementation; main boundaries independently require a real tumor/non-tumor adjacency.

## CNA support: project adaptation, not a transferred paper threshold

The existing source-adapted CNA clusters are summarized using per-bin cluster median consensus. We retain separately: spot `mean(CNA^2)`, mean spot MSQ within a cluster, and `mean(cluster_consensus^2)`. These are not interchangeable. Consensus correlation to the unweighted mean of cluster consensuses is reported, but not treated as a universally valid malignant reference.

Ordered autosomal profiles are summarized in 20 Mb genomic windows with at least 10 bins spanning at least 10 Mb. The reference is the per-window median of native high-confidence diploid spots when at least 50 are available; otherwise the lowest-burden quartile is a technical reference, explicitly not certified normal. Window deviations are relative to that reference in unchanged native units. The genome-wide median of window deviations is retained as a separate global offset. Chromosome-specific contrast subtracts this offset; this is an explicitly labeled contrast, not rescaling of the native profile. An event has absolute structured contrast at least `max(0.04, 3 * 1.4826 * reference_MAD / sqrt(cluster_n))`. This is an operational regional-pattern rule, not a calibrated significance test. Adjacent windows and their direction, genomic span and magnitude are saved for inspection.

Coherent multichromosome patterns require cluster size ≥10, median spot-to-consensus correlation ≥0.3, and events on ≥2 chromosomes (or ≥1 with native aneuploid fraction ≥0.5). A coherent cluster with native aneuploid fraction <0.5 is explicitly `coherent_pattern_native_diploid_conflict`, not strong malignant evidence. Smaller/weaker coherent patterns are moderate; baseline-uncertain strong patterns are downgraded. Automatic references not externally validated are distinguished from baseline uncertainty and are not all declared failures. Low-confidence diploid remains separate from missing results. Broad RNA-derived deviations may reflect expression/state/reference artifacts: the heatmap and native-label discordance must accompany their interpretation.

The TNBC repository's `1copykat.R` uses cluster-median-consensus MSQ plus reference correlation, whereas other scripts use spot-MSQ/purity rules on different scales. Published Methods and scripts do not justify transferring a single cutoff to this project. We use the explicit regional-window implementation above, retain the separate original quantities and do not rescale profiles to meet literature thresholds. Both SpaCET and CopyKAT are RNA-derived; agreement is not independent DNA validation.

## BANKSY tissue domains

Each section starts from the full transcriptome and selects up to 3,000 HVGs using scran variance modeling. Library-size normalization, official BANKSY harmonics (including AGF), PCA (30 PCs), and Leiden clustering are used. For ordinary Visium, the official recommended starting spatial mixing weight is lambda=0.2, with k_geom=18; primary resolution=0.6 and k_neighbors=30. Pilot sections also run resolution=0.4 as a limited sensitivity comparison. Pilot adjusted Rand indices are 0.484–0.841, indicating variable stability of fine domain boundaries, especially T3. Under the same annotation rules, changing only this domain resolution changed 2 of 42,087 pilot tumor-mask labels; the main mask primarily reflects spot-level malignant/CNA evidence rather than a forced domain-wide identity. No MP10 or target-cell enrichment is used for parameter selection.

**Project extension:** unrestricted spatial kNN is replaced by the retained-tissue six-neighbor lattice's ≤2-hop graph (up to 18 neighbors). Distances, median-Gaussian weights and angular harmonics use the same official formulas; only the neighbor candidate graph is restricted. This prevents jumps across missing rows/holes and disconnected tissue fragments. No cross-section neighbors are built. Domain IDs are not pathology classes. Domain summaries contain malignant fraction, existing CNA evidence, c2l composition and marker programs; spot-level heterogeneity is retained.

## Joint tissue annotation and main mask

The exact executable rules are in `scripts/annotate_plot.py`. The old epithelial gate is used only for the final comparison table, never as an entry gate or tumor criterion.

- Non-depth SpaCET malignant fraction ≥0.5 supplies initial tumor candidates. Coherent native-aneuploid CNA with domain context supports mixed candidates or rescues low-epithelial-fraction spots. Supporting expression is a multi-gene epithelial program, not a c2l epithelial fraction gate.
- Muscle-dominant candidates (SMC fraction ≥0.5, the multi-gene muscle rule and low epithelial-program expression) are localized conflicts unless a documented H&E context supports the muscle identity. This final check affected 83 additional positions in four non-adjacent-source sections; it does not discard low-c2l-epithelial CNA candidates at an entry gate. Strong immune composition inconsistent with epithelial expression and lacking strong CNA is a localized conflict. Seq-depth-only candidates remain unresolved unless supported otherwise. Adjacent-normal sources with malignant estimates require additional scrutiny; they are not forced to zero before estimation.
- Immune-rich identity requires immune major-lineage fraction ≥0.5 and ≥2 expressed immune markers. Stromal identity requires stromal fraction ≥0.45 and matching multi-gene stromal/endothelial/muscle expression. Smooth-muscle-rich identity requires SMC fraction ≥0.25, ≥3 muscle markers, MYH11 and ACTG2 or CNN1. ACTA2 alone is not used to name muscle. These are composition-based annotations, not independent discoveries about enrichment.
- Context-assisted reassignment of adjacent-normal epithelium is not an independent specificity validation. Normal urothelium requires adjacent-normal source plus differentiated urothelial expression and supporting context; low CNA alone is insufficient. A recorded H&E surface-lining comparison can support an inferred normal label while retaining a high-SpaCET conflict flag. Uroplakins also occur in luminal tumors, so urothelial markers alone cannot establish benignity. `tables/morphology_context.tsv` documents assistant image comparison only, without invented pathologist names or review dates. It cannot exclude dysplasia/occult tumor.
- Ambiguous epithelial identity remains local Uncertain/conflicting. Mixed tissues without stronger evidence are Other tissue. Necrosis, acellular regions, muscularis propria and TLS are not assigned without adequate morphology. There is no requirement for every section to contain all categories.

A final local H&E comparison in GSE285715_N2 identified broad muscle bundles with SMC-dominant composition and MYH11/ACTG2/CNN1 expression, despite concordant RNA-based malignant/CNA estimates. Muscle-supported, low-epithelial-expression positions were assigned Smooth-muscle-rich region with an explicit malignant-model conflict flag; residual tumor candidates in this adjacent-source section are excluded from priority boundary analysis. This is evidence-based local adjudication, not an epithelial-fraction entry gate.

There is no smoothing, island deletion, hole filling or optimization toward an expected tumor shape. All main-mask changes relative to the initial SpaCET cutoff carry reasons. `review_status` remains `no_documented_human_pathology_review` throughout. High computational concordance is not pathology confirmation. H&E overlap permits correspondence checks but does not replace expert histology review.

## Main boundaries and distances

Actual Visium six-neighbor offsets are (0,±2),(±1,±1). Adjacent hexagons share an exact edge after fitting the validated lattice-to-image affine map. A biological interface requires a Tumor spot and an adjacent, known non-tumor tissue spot; uncertain neighbors and absent/QC/capture-edge neighbors never create an interface. Small supported tumor nests are retained.

First-ring main bands are tumor interior, tumor inner margin, peritumoral outer interface and distal non-tumor. Two-ring bands are saved as sensitivity results. Ring depth is graph-based. Continuous distance is the minimum Euclidean distance to an evaluable shared edge, inside its own tumor component or outside within its retained-tissue component. Inside is negative; outside positive. Unassessable interfaces stay missing. Native distance units are aligned-image pixels; `signed_distance_dNN` divides by median neighbor spacing. No unverified micron conversion is made. Tumor–stroma, tumor–immune-rich tissue, tumor–normal epithelium, tumor–smooth-muscle-rich tissue and tumor–other edges retain outside identity. Tumor boundary is not automatically called an invasive front.

## Outputs and interpretation

Each section has core H&E/region/malignant/CNA/band panels, distance/native/BANKSY panels, chromosome profile heatmaps and a standalone categorical map, in vector PDF and 300 dpi PNG. H&E remains raster within PDF; CNA heatmaps are compressed raster layers with vector labels. Original H&E inputs remain intact. Spot tables, domain summaries and boundary edges accompany the figures. Missing continuous values are gray, not zero.

A section with ≥20 inner, ≥20 outer and ≥20 core positions is geometrically eligible; high local uncertainty or unresolved evidence still constrains its biological use. This count rule is a practical availability flag, not a statistical power calculation. Later MP10/microenvironment comparisons must account for dataset, section/patient identity and spatial dependence, and must not present annotation features as independent validation.
