3. 两种稀释规则

规则 A：TARGET_UMI，复现旧逐 spot 定额规则
对每个 bag b、深度 d：
p_target(b,d) = min(1, T_d / S_b)
对该 bag 中每个细胞的每个基因做整数 Binomial thinning，再求和。
这是期望 UMI 锚定，不要求随机结果精确等于 T_d；不足深度不能上采样。

规则 B：FIXED_CAPTURE，全局固定捕获率
在模拟前，使用本轮冻结的 unique DEV bag 的 S_b，一次性计算：
p_mid = T_mid / median_b(S_b)
p_low = p_mid * T_low / T_mid
p_high = p_mid * T_high / T_mid

每个深度的 p_d 对全部 bag、sample、dataset、细胞类型和基因都相同。
不逐 spot 调整 p，不在 thinning 后将每个 spot 重新缩放到 T_d。
固定捕获率组中，不同 spot 的实际 UMI 应当允许不同。T_d 只是典型深度锚点。
这个中位数仅用于冻结模拟的技术参数，不改变训练细胞及标签范围。

若某个全局 p_d > 1，将该 FIXED_CAPTURE 深度标为不可通过 thinning 实现并记录；不静默 clip、不上采样、不临时选择更有利的锚点。继续执行可实现深度与其他模块。

对同一 bag 的两种规则及不同深度保持明确配对。使用确定性随机种子；可用嵌套 Binomial thinning 减少额外模拟噪声，但必须保留每种规则正确的边缘分布并说明实现。
若没有全基因逐基因缓存，允许使用可核验 G0 原始 counts，加上每细胞 full RNA 与 G0 的 UMI 差额，对未保留部分作数学等价的 Binomial 总量抽样；不能伪造缺失基因列。
记录每个细胞/类型的实际保留 RNA、zero-retained-RNA 标记。即使某细胞保留 RNA 为零，其真实细胞计数仍然保留。
两种规则最终都截取相同的 G0 输入；两份 reference 使用字节相同的对应 counts。

D. 分层与统计单位
