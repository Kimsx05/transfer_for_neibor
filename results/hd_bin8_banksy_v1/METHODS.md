## Controlled computation

Each section is independent. Seed 123; same normalized input (scale.factor 10,000), same frozen original RNA HVGs, global scaling with upper cap 10, 30 PCs, Annoy Euclidean k=20/50 trees, SNN pruning 1/15, Louvain algorithm 1, resolution 0.5, 10 starts/10 iterations. Native lazy C++ PCA avoids a full dense BANKSY assay. Own and neighborhood features receive sqrt(1−λ) and sqrt(λ) weights. All λ branches use the same implementation; no second ScaleData. Names and files are branch-specific. Historical `cluster_projected` used sketch/resolution 0.8 and is descriptive context, not the matched baseline.

UMAP uses UWOT cosine, 30 neighbors, min.dist=0.3, spread=1, 200 epochs, seed 123. Seurat obtains thread count from future workers; workers=8 is explicitly set during UMAP, then reset. Numerical threads capped at eight, BLAS at one, jobs nice 10; main models are sequential. Versions and exact package path are in each `model_versions.json` and `sessionInfo.txt`. An initial UMAP invocation ignored a non-supported thread argument; it was stopped and resumed from saved PCA/clusters with the supported worker setting. No finished biological result was replaced by a parameter search.

## Spatial neighbors and coordinates

Physical x/y are inherited, in μm; y increases down the image. Plots show x and −y. D1 crop origin and all image transforms remain those of the previous pipeline. IDs are strictly checked at every join.

Before applying the expression QC threshold, connected components are obtained from the supplied native 8 μm in-tissue grid (8-connectivity). Actual neighborhood search uses every valid QC bin within its component, excluding itself, with k=min(50, component_size−1). This prevents edges across disconnected supplied tissue pieces without splitting global expression scaling. It is independent of reference labels. Native `kNN_median` weights are exp(−d²/median(d)²), normalized for each target. There are no singleton components among QC bins. Small components have fewer than 50 neighbors; none are removed. Boundary distances refer to the supplied native in-tissue mask and can reflect input coverage, not just an anatomical tissue edge. Neighbors can still span holes or sparse stretches within a component; actual per-bin distances are retained and >80 μm is a descriptive review flag, not a filter.

Cervilla image regions without supplied bins remain outside the analysis and are shown using the inherited coverage overlay. They are not Unknown, low-expression tissue, or domains.

## Annotation and expression evidence

BLCA and HPCA raw/pruned candidates are separately mapped to Epithelial; Mesenchymal (Fibroblast+Mural); Endothelial; Immune (T/NK+Myeloid+B+Plasma+Mast); Unknown (missing). HPCA does not independently cover Mural/Mast/Plasma. Coarsening is not a consensus or an improvement in measured accuracy. Comparisons explicitly separate all-QC, both-candidate and original-HPCA-covered denominators. SingleR scores/pruned labels remain candidate support, not probabilities.

All expression interpretation uses original RNA counts/data, not BANKSY neighborhood expression. Marker summaries cover the full QC set and all available panel genes. Descriptive all-gene cluster markers use log2(1+mean normalized expression) in/out and positive-bin detection differences; retained candidates require pct_in≥0.1, delta_pct≥0.05 and effect≥0.25, ranking up to 40 per cluster. These thresholds select a readable evidence table, do not exclude bins or define cell identities. No P values treating spatial bins as independent biological replicates are computed. Displayed DotPlots focus on the largest 25 clusters; tables retain all clusters.

Cluster SingleR uses existing frozen 44,896-cell BLCA training and the existing HPCA major-class training. BLCA uses original Ensembl IDs. HPCA merges duplicate-symbol raw counts in a temporary view, then LogNormalize, exactly as the previous per-bin analysis. Cluster sums of this unsmoothed expression are classified and pruned together by section/branch/reference. Scores are pre-fine-tuning correlations; delta.next is the official output. Small clusters and mixed aggregate labels require caution. Existing RCTD and BLCA share a reference and are correlated evidence.

## Incremental storage and loading

Only metadata, embeddings, evidence tables, code and figures are added. No repeated counts, full Seurat/h5ad, reference copies, or retained dense BANKSY matrices. `code/load_result.R::load_banksy()` resolves the sibling input directory and attaches fields/reductions by unique bin ID. The original input must remain available. Temporary HVG/neighbor caches can be removed after successful validation; rerun reconstructs them only if model branches are missing. `review.zip` excludes embeddings and all expression/reference data.

Region explanation starts from a transparent descriptive summary: median nFeature<20 marks information-limited clusters; both epithelial and fibroblast panels detected in ≥35% of bins and co-detected in ≥20% supports a mixed-signal label (not necessarily a spatial boundary); otherwise the largest marker-panel detection support ≥20% gives a provisional enriched label. Concordant dominant reference composition with only ≥5% panel support is explicitly called sparse support. Remaining clusters are unresolved. These are interpretation-table labels, not new QC, cell identities, or calibrated confidence. Large/important clusters are reviewed against marker tables, H&E and spatial maps; any reviewed changes are listed in `reviewed_region_overrides.json`. `review_status` distinguishes these from summaries only. No requirement that all clusters fit four types is imposed.

Environment note: an initial isolated attempt to install newer upstream Banksy could not resolve dependencies in that subprocess. It was not used. Existing project Banksy 1.9.5 was then found and reused successfully. `sources/upstream_DESCRIPTION_not_installed` is documentation context only; `model_versions.json` and `sources/installed_Banksy_DESCRIPTION` identify the code actually run.

The native PCA core's `total_var` (stored as `total_variance` in the incremental bundle) is the sum of squared retained singular values, not total variance over all input dimensions; no explained-variance claim uses it. PCA loadings in the bundle include original and `.m0` feature blocks and should not be treated as unsmoothed RNA marker expression. The loader attaches embeddings; original RNA assay remains the expression source.

For region summaries, Plasma panel support additionally requires an existing plasma-core marker (MZB1/JCHAIN/TNFRSF17/DERL3) exactly as the previous annotation's support logic. Raw `detected_Plasma` is retained unchanged; `Plasma_core_supported_ge2_fraction` records the additional evidence. This prevents immunoglobulin-only signal from automatically naming an immune region. Clusters with epithelial and collagen signal distributed across different bins can be described as an epithelial-stromal composite region, distinct from frequent same-bin co-detection.

Cache reuse checks the source RDS path/size/modification time and the small frozen HVG list fingerprint, plus completed-branch parameter records. It does not hash whole matrices or the server. Changed source/HVG/configuration must not be silently combined with old branches. Actual final loading checks counts, IDs and coordinates against the source independently of these cache checks.

Louvain retains Seurat's default `group.singletons=TRUE`: only singleton communities are reassigned using expression-SNN connectivity; no bins or small non-singleton clusters are deleted. Installed `GroupSingletons` internally uses seed 1 for connectivity ties, consistently in all branches; requested model/PCA/Louvain/UMAP seed is 123. This is not a spatial majority-vote annotation step. Reported cluster counts are final Seurat clusters after this standard handling.

UMAP runtime diagnostics are retained in `tables/UMAP_runtime_diagnostics.tsv`. D1's approximate UMAP neighbor recall is lower than Cervilla's (about 58–69% versus 84–100% in the completed runs); λ0 also reports smooth-kNN calibration warnings (Cervilla 8,221; D1 10,455). All saved embeddings are finite and cover the full QC set. No visual separation in UMAP is used as standalone evidence of biological identity or domain accuracy. Primary interpretation uses physical coordinates, original RNA evidence and H&E; the expression-SNN clustering is computed before and independently of UMAP. No parameter sweep was performed to beautify the embedding.

Expression neighbor/SNN graphs are freshly constructed within each branch and released after clustering; they are not attached to or substituted for the source object's graphs, nor saved in the incremental bundle. `graph_name` in branch parameters is the branch identifier. Future graph reconstruction can use the retained full PCA and recorded neighbor settings. Frozen SingleR settings are inherited: BLCA single-cell reference uses Wilcoxon marker selection with reference aggregation; HPCA uses its existing classic-marker major-label model. No reference cells are resampled or models retrained in this round.
