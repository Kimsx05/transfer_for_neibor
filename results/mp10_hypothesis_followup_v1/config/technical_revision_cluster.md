# Input field repair (no hypothesis or threshold change)

The original Epi cluster field is `epi_allgene_cluster` in `mp10_subtype_screen_round1/tables/epithelial_existing_metadata.tsv.gz`, as used by v1 `06_abundance_confounding.R`. `subtype_v2` is not this field and was missing for the Epi cells used here, producing a constant covariate and rank-deficient sensitivity models. The implementation now joins the exact original barcode mapping and uses the globally largest existing cluster (required to be >=5% of original eligible Epi) as the predeclared single composition covariate. Missing original cluster labels remain separately recorded and in the total-Epi denominator. No clustering or subtype reassignment was performed. The pre-repair result table is retained; primary models are unchanged. This repairs an input-field implementation error, not an effect-driven covariate selection.
