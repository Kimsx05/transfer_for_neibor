# Epithelial-associated bin niche methods

Inputs are read-only sibling extension/comparison tables. No upstream expression, SingleR, BANKSY, RCTD or segmentation rerun. No MP10 values enter any step. All analysis units are bins/anchors, not cell counts. MPBC tissue membership remains NA.

## Frozen geometry and features
All supplied nodes retained in nodes.parquet. Native analysis QC and known/pruned candidate states remain distinct. Pool for types is all original analysis-QC bins, including missing labels. Geometry is within section and 8-connected supplied support (original tissue support for the three masked sections), never type-defined. Physical x/y are inherited; y increases down, MPBC coordinates are relative array positions. Theoretical circular counts are nominal infinite 8um lattice values, not verified tissue coverage. `n_supplied_component` includes supplied positions in the permitted component; `geometric_coverage.parquet` additionally counts all supplied positions irrespective of component/tissue and original-in-tissue positions (NA for MPBC). Missing coordinates are not zero-expression measurements.

Shared centers: native QC, either reference's unpruned Epithelial candidate, and >=2 distinct genes among EPCAM/KRT7/KRT19/UPK2/KRT5/KRT14/KRT6A/KRT6B/KRT17/COL17A1. Existing disjoint six- and four-gene raw detection counts are summed. These panels were actually reviewed across urothelial and basal/squamous-like regions in the extension; no new marker threshold is optimized against niche maps. Collagen support remains a mixed flag, not exclusion.

For each ref/radius, exact cKDTree radius queries count all eligible neighbors per category, subtract center if it belongs to that category, retain other Epi bins. Radius200 is cumulative and includes radius50. No kNN approximation, no UMI weighting, no pseudocount. Unknown/NaN excluded from both numerator and denominator; known proportions sum to1. Fixed BLCA9/HPCA6 category order is type_mapping.json. HPCA's absent Mast/Plasma/Mural are never inserted as biological zero columns. Shared C/P saved once per section/radius, used by both methods. Unknown fraction is1-known_fraction among analysis neighbors, low-info and reference-conflict fractions also use analysis neighbors. Input coverage uses nominal geometric positions and is not tissue coverage for MPBC.

Support frozen after reviewing support_before_models.tsv: n_known>=10, limiting a single vote to at most10%. No known-fraction, Epi-purity, non-Epi-count or type-diversity threshold. This is an operational exploratory support minimum, not a universal optimum. Edge and low support remain interpretation caveats; n_known=0 receives no manufactured composition.

## Common training and two methods
Training uses identical S/P/T within ref/radius. Seed123, 400um blocks, round-robin random within blocks, <=20000 per Cervilla/D1/UC/MPBC1, MPBC2 projection only. Sampling centers never samples their neighbors. Physical blocks reduce dominance of dense adjacent anchors; they do not make overlapping neighborhoods independent biological replicates.

A: sklearn MiniBatchKMeans on sqrt(P), all full types including Epi; no scaling/PCA/Harmony. n_init10,batch4096,max_iter200,max_no_improvement20,tol1e-4. K2–8, seeds123/456/789. B: Squidpy1.8.4 public calculate_niche_neighborhood baseline, scale=False,abs_nhood=False,distance=1, n_neighbors15 in composition space, igraph Leiden,n_iterations=-1,min_niche_size=None,rng123. Resolutions .1/.2/.4/.6/.8/1.0. B uses raw P, not sqrt(P). Difference is both transform and clustering, not clustering alone.

Public API receives all supplied nodes, categorical true NaN and fixed categories, N×N binary CSR with only T rows containing their complete physical neighbors, no diagonal, no symmetrization. It is a training-center query graph, unsuitable for multi-hop/centrality. Non-T zero embeddings are layout artifacts and never used for prediction. Main API P_T checked against shared exact P. Stability runs reuse frozen P_T through version-pinned `_niche.calculate_niche_custom` plus the package's `_leiden_clusterers`; no alternate clustering algorithm. Artificial geometry/NaN test and real ROI full/query-row graph native label equivalence run before full models.

Selection is declared scalar descriptive score .5 seed ARI + .3 physical-block ARI + .2 silhouette (fixed random2500 training subset). A block stability fits without one of five spatial-block groups then compares predictions; B compares refits on retained blocks. These differing estimands are not identical stability tests and are not method-accuracy rankings. Parameters chosen within method only. Weak discrete support remains exploratory. No niche-size deletion or forced cluster count.

A predicts remaining S in sqrt(P), retaining nearest-centroid distance and relative separation. Outliers beyond1.5×training99.5th percentile nearest-centroid distance are unresolved. B external kNN15 on raw P; zero-distance neighbors take precedence, majority with lexical label ties; <=50% support or distances beyond1.5×99.5th percentile held-out-block nearest-training distance are unresolved. T native labels are always preserved. Votes/distances are not probabilities. Projection is external to Squidpy. Candidate labels remain even when final assignment is unresolved.

## Exact-composition ambiguity
The first completed BLCA50 native run assigned4608 identical pure-Epi training profiles to89 distinct Leiden labels. This is a composition-space kNN/tie/partition sensitivity, not89 biological environments. Exact duplicated training profiles are therefore explicitly audited for every branch. External zero-distance assignment considers ALL training rows with exactly that P (not an arbitrary15 of many zero-distance neighbors); lexical maximum-vote tie handling, majority>0.5 unchanged. Ambiguous exact profiles remain unresolved outside T, while T native labels remain untouched and flagged. Positive-distance kNN remains15. This correction addresses demonstrated projection tie ambiguity, not niche tuning or reannotation. B discrete labels in such profiles are exploratory and unsuitable as independent biological categories.

## Delivery and implementation notes
The small cache contract records definition-code/config hashes and metadata size/mtime, not whole-expression checksums. It rejects changed inputs/definitions instead of silently mixing caches. The isolated Squidpy environment uses Scanpy1.12.5; the prior analysis environment's Scanpy1.12.4 was not upgraded. Actual package versions and R loader versions are delivered. Models were executed inside the authorized night window with numerical threads capped and model CPU affinity restricted to4 cores. No full radius graph is persisted.

Two diagnostic fraction columns initially became NA through pandas integer-index versus bin-ID alignment; explicit NumPy assignment repaired only these support columns. All type C/P, training and model inputs were unchanged. Direct geometry checks and final plots verify finite support fields. Arial is explicitly registered from the existing project host font; no substitute font is claimed. Dense spatial point layers are rasterized inside PDFs while text/legends and statistical elements remain vector. A colors align only the demonstrated higher-Epi versus composite ordering. B colors are independent arbitrary labels by reference/radius; full paginated legends accompany compact map legends. B composition overviews show largest31 labels plus a size-weighted display remainder; full per-label tables retain every niche without merging model labels.

R and Python loading functions attach by ID, retain original expression and QC, and leave noncenters without niche labels. All five actual upstream Seurat objects were reread and attached once; identical original counts and QC and unassigned noncenters verified. `training_anchor_ids.tsv` is per reference/radius; both methods reuse that exact file. `squidpy_niche_train` and `squidpy_niche_projected` separate native from external candidates; B_reason and B_assignment_source distinguish ambiguous/extrapolated/unresolved states.
