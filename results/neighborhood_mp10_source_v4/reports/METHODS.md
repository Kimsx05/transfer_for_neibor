# Methods and interpretation

Frozen SAMPLE_R12_LEIDEN labels 0–8, q05 environment and c2l mean Epi gate are untouched. Formal labels exclude UNASSIGNED from niche summaries, while all common anchors remain in the full table. Patient identities use the accepted overlay; anonymous policy units are not relabeled as known patients.

Historical Top20 AUCell is the recovered Python average-tie rank implementation: raw counts, K=ceil(.05*G), sum(max(0,K-rank(signature)))/sum(K-r), r=1..min(signature size,K). It is not an assertion that the historical code exactly reproduces R AUCell random tie handling. Original frozen values are retained; predetermined first12 centers per section are reproduced.

For saved joint posterior means, conditional Epi counts=observed counts*(w_Epi*reference_Epi*m_g)/(w@reference.T*m_g+batch ambient). Detection cancels in the ratio. This is a plug-in attribution, not the posterior expectation of the attributed counts. No Epifraction multiplication or template-only expression was used. Full ordered model genes form the shared ranking background for observed/Epi scores. Fractional attributed counts are not rounded. Primary scores require all20 genes; B5 lacks HMGCS1 and is kept separately as partial sensitivity. Signature observed counts=0 yields NA count shares. All-zero Epi counts yield NA.

The installed official compute_expected_per_cell_type was compared at <=128 deterministic anchors per dataset, all30 types plus ambient reconstructing observed counts. Model restore was actually attempted successfully; scvi's Pyro on_load internally invokes one initialization step before loading saved state. This did not overwrite saved models or run full training. Subsequent validation uses the installed official function with exact saved reference/registry access to avoid repeated loader initialization. Full execution reads saved posterior means only.

Section-niche versus rest median differences use at least20 anchors in both groups. Rest composition varies across sections. Sections of the same accepted patient/unit are bundled by averaging their section effects; >=5 units permit exploratory1000-resample unit bootstrap intervals. No iid spot P-values or SEs are reported. Intervals are exploratory, unadjusted across the nine contrasts and are not confirmatory tests. Source categories are conservative descriptive adjudications; when the Epi interval crosses zero, no MODEL_ASSISTED_EPI_SUPPORT is assigned. Attenuation means a smaller point effect with unresolved Epi interval, not a numerical fraction of source explained. A predefined section+niche+bs(Epi,df3)+log1p(nCount) regression provides descriptive coefficients only. Complete rings, Epi>=.5/.7, candidate labels, largest-dataset exclusion are sensitivity summaries, not new clustering or external validation.

Source controls reuse9600 observed scRNA count profiles with verified32-to30 mapping; no independent malignant identities inferred. Existing fixed-W NNLS original EpiMP usage is reused where exact cell ids match. Composition-only blueprints use actual central mean30 cell proportions, each donor's unnormalized model-gene counts (retaining library-size differences), and exact observed central library depth within the same model-gene background. The same Epi donor set per repeat applies across all niches; other cell types change with actual composition. Five repeats are technical simulations, not patients. State controls keep non-Epi realized counts and total depth fixed; only the Epi profile changes. True Epi counts are saved. This does not validate abundance estimation end-to-end.

No saved matched joint posterior draws were found; draw-level uncertainty was not estimated. Independent q05 margins were never combined as a draw.

Sources: [cell2location official implementation](https://cell2location.readthedocs.io/en/latest/_modules/cell2location/models/_cell2location_module.html), [AUCell vignette](https://bioconductor.org/packages/release/bioc/vignettes/AUCell/inst/doc/AUCell.html), local installed source and frozen historical scoring script (see audits). Min20/min5/bootstrap1000 are project working rules, not universal statistical standards.
