# Cervilla MP10–T-lineage / endothelial precommunication methods

## Scope and provenance

Cervilla is the only formal spatial-analysis section. D1_Johnson receives a raw marker/registration/MP10 measurement check only. No communication, ligand–receptor, NicheNet, TF, CNV, malignant-state inference, ordinary Visium reanalysis, or four-method niche rerun is performed. Upstream files are read-only. No applicable AGENTS.md was found in project ancestors or the HD project. Input history was read through AUDIT_REPORT, the recovery correction, assignment v2 and bin8 reports, loaders, and actual objects.

`input_manifest.tsv` records actual paths. Cells come from `../segmentation_assignment_v2/Cervilla`: the existing StarDist nuclei and deterministic nearest-nucleus assignment out to 8 μm, not fixed 8×8 μm bins. Counts are integer sums of supplied 2 μm counts; no new whole-section segmentation. Analysis QC is the existing >=10 genes and >=10 counts plus input/image validity, unchanged. Nuclear-center x/y (right/down) in μm is used. Cervilla native mpp=0.8636122748145504; D1 mpp=0.2478437292776258 with the original crop origin (23764,35851). Missing supplied coverage is not measured zero, Unknown tissue, or Treg absence.

8 μm bins use the recovered **native** matrix under `../hd_bin8_comparison_v1/Cervilla/native8`. The 16 μm branch sums all supplied native 8 μm counts with row16=floor(row8/2), col16=floor(col8/2), fixed original origin. No bin QC precedes aggregation. All 18,085 genes are retained. Supplied child counts and tissue-support counts are stored; partially supplied parents are not completed with observed zeros. A parent is expression-QC eligible if it has supplied in-tissue support and >5 UMI; mixed/partial support remains explicit. Per-gene and global sum conservation is in `tables/bin16_gene_conservation.tsv`. Native8 input totals differ slightly from the older supplied2 input because of barcode/edge masks; no false claim of equality across different inputs.

## Fixed comparisons and fine reference

Eight 256 μm ROIs were fixed before associations: five inherited ROIs, maximum measured T-lineage-panel and endothelial-panel UMI blocks (>=250 QC bins), and a measured nonimmune control. Selection uses no MP10 relationship. Coordinates/reasons: `tables/roi_manifest.tsv`. The images are recovered H&E, not new higher-resolution measurements.

The fine reference is `subtype/v2/reference_training_v2/11_final_spatial_reference/reference_v2_final_30type_regression_input.h5ad`, with 300,033 exact frozen members and 30 spatial identities. Its mapping preserves Treg, Tfh/CXCL13-like, CD4 helper/conventional, CD4 naive/memory-like, two CD8 types, NK, four EC types, and all non-target background lineages. The spatial-only historical merges are C1QC/FOLR2 TAM and Naive/Memory B; no target-driven new reference merge is made. Original sample and dataset fields are retained. Every fifth sorted `orig.ident` is held out; this is **sample holdout**, not verified independent-patient validation. Training is round-robin balanced by sample within type, up to 600/type and 1,800 Epithelial. Holdout contributes up to eight cells/type/sample. The membership table, not nominal caps, defines actual membership.

HD feature ID→symbol mappings come from its original gene table. Duplicate symbols are summed in raw counts before normalization; the original objects remain unchanged. Reference uses its curated unique approved symbols. There are 13,960 common model genes after removing TIGIT. SingleR is trained on these full shared genes (not HVGs), Wilcoxon differential features, aggregated reference, seed123. RNA is library-normalized to10,000 and log1p. Every original QC Cervilla cell is directly predicted; there is no sketch label propagation. Outputs are merged before one pruning operation. Scores are correlations, not probabilities. Actual selected genes, including whether each target marker entered the classifier, are recorded separately from gene availability.

Target confusion is evaluated on held-out raw single cells thinned to expected100/300/1,000 UMI, with complete 30-class competition. It is an internal reference/platform check, not HD ground truth or bin-mixture validation. TIGIT is absent from both SingleR and the matched RCTD reference counts, leaving it as a readout.

RCTD uses installed **spacexr2.2.1**, `create.RCTD` / `run.RCTD`, not the differently named modern Bioconductor API. Both ROI bin sizes use the same fine reference and doublet mode, UMI_min100, UMI_min_sigma300, counts_MIN10, max_cores4; all actual package defaults are in `models/*RCTD_config.json`. The model fits one or two dominant contributions, not a biological claim that a bin contains at most two real cells. `weights_doublet` has **first_type/second_type positional columns**. These are mapped using each row's actual identities; their order is never treated as fixed cell types. Raw weights and all statuses are preserved. Singlet/doublet_certain are distinguished from uncertain/reject/not-run/gate-excluded. Secondary weights in singlet fits are not automatically credible identities. No SingleR score becomes a fraction.

A bounded additional cell comparison reads the **existing** 4 μm aggregation within the same ROIs, preserving nucleus/object IDs. It is not a new segmentation. Raw panel counts, fine predictions, count differences and provenance are retained. No whole-section boundary is changed.

## Target support and unit selection

Unit selection is frozen in `tables/unit_selection.tsv` after measurement/ROI comparisons and before niche–MP10/target associations. Broad candidates require reference agreement with raw lineage-panel support (two Epi/EC panel genes, one for other broad lineages). T-lineage needs raw T evidence and lacks the explicit Epi/collagen cross-lineage flag. Uncertain T subtypes remain `T_subtype_unresolved`, not automatically NK or Treg. Treg is not established by FOXP3, TIGIT, or a classifier alone. The conservative object-level target check combines reference prediction, heldout performance at300 UMI (precision>=0.7 and recall>=0.4), >=300 raw UMI, T-lineage evidence, at least two of FOXP3/IL2RA/CTLA4/IKZF2/LRRC32 with FOXP3 or IL2RA present, and no detected cross-lineage mixture. This is an operational supported-candidate definition, not a universal scRNA QC filter. No object or raw count is deleted for failing it. Candidate-group aggregate expression, 8/16 μm RCTD and 4 μm ROI results are also reviewed so that a sparse single-object gate alone does not determine biological absence.

The full mutually exclusive composition layer contains supported major groups, supported T subtypes when justified, and lineage-known/subtype-unresolved categories. Unknown is retained but excluded from biological composition features. A failure to establish Treg is an **unmeasurable target**, not zero Treg abundance. Formal Treg endpoints remain NA, including reverse Treg/Tconv/Tfh analysis if identity cannot be established. CD4/Tfh confusability is retained rather than forced into denominators.

## MP10 measurement: important implementation distinction

The frozen Top20 file matches all20 user-specified genes, including SLC20A1/ADIPOR2/MXD1; it is not Core19. The exact historical code is `neighborhood_mp10_calibration_v5/code/common.py::auc_parts`, reused for formal `MP10_cell` by `mp10_subtype_screen_round1_v2/scripts/01_prepare.py`. It uses **average tied ranks**, K=ceil(0.05×all measured genes), and sum(max(0,K−member_rank))/sum(K−1,...,K−20). With18,085 HD genes, K=905. The original formal score is not the random-tie AUCell package implementation. This distinction was resolved and corrected before any association, with exact dense-SciPy versus sparse historical-formula checks (`historical_score_validation.tsv`, error0).

Installed AUCell1.32.0 is a method sensitivity: native random ties and `keepZeroesAsNA=TRUE` are checked on bounded raw matrices, three fixed seeds, and its realized rankings are verified against the AUC formula. Native random zeros can enter the top5% in sparse HD and are unstable. This **does not mean that historical average-tie scores suffer that same random-zero problem**. All plots/tables distinguish historical primary scores from native sensitivities. No gene set, aucMaxRank, or score was selected by MP10–target effects.

Only credible Epi objects supply the primary score. Epi centers with detectable Epi/collagen/T/EC mixture stay in the niche center set, but they are not used to claim epithelial-specific MP10. Limited single-object support prompted the prespecified **64 μm epithelial-only regional measurement**: fixed global physical grid, input component separation, further connected components with Epi-to-Epi links<=16 μm, at least five credible Epi objects, at least five detected Top20 genes, and >=905 detected genes so the AUC window is supported by positive expression. This is a score-eligibility rule, not a new universal expression QC. It does not establish exact pathological boundaries; narrow unknown interfaces remain a limitation. No TME/Unknown expression is pooled, no score is divided by Epi fraction, and regional scores are not replicated into independent cell observations. Membership and counts conservation are stored, enabling score reconstruction from the upstream count object without another expression copy.

Primary MP10 is continuous historical rank-AUC. Seed-native, half-depth, and expected3,000-UMI thinning assess measurement sensitivity. Type7/linear Q50/Q90/Q95 across all eligible Epi regions defines L50<=Q50,H50>Q50,H10>Q90,H05>Q95, with the same L50 control. Ties are not split. Missing/unsupported scores are never Low. Region eligibility, cell center eligibility and association eligibility are separate.

## Composition and niches (frozen before association)

Physical cumulative50/200 μm circles use all original analysis-QC cells as the neighbor pool within each input component. Center itself is excluded; all other Epi and TME objects are included. Unknown is omitted from both the type-count numerator and conditional known-type denominator. Counts are objects, not UMI or SingleR scores. Observed tissue/input support is estimated from native8 μm positions and retained independently. Niche eligibility requires >=5 known neighboring objects and >=25% observed circular area; no non-Epi minimum, rarity z-scoring, coordinate/quality covariate, MP10 feature or harmony is used. Formal association further requires a majority-observed circle; these are measurement support rules, not evidence of complete true cell detection.

Hellinger=sqrt(full known-type P) feeds KMeans(n_init20,max_iter300). K=2/4/6/8, seeds123/456/789, common400 μm spatial blocks. Training caps150 centers/block without removing any neighbor. Candidate checks include seed ARI and worst matched-cluster Jaccard plus deterministic held-out-block refitting. The smallest finer K satisfying seedARI>=0.8, blockARI>=0.6 and minimum matched-cluster Jaccard>=0.4 is the work resolution; otherwise K2. K2 is always retained. This limited stability diagnostic is descriptive and does not pretend blocks are independent patients. No MP10 or target association contributes to selection/naming. `niche_frozen.json` precedes association execution. Niche labels apply only to Epi centers; they are not propagated to their entire neighborhoods.

## Associations, uncertainty, and missingness

The independent scoring unit is an Epi-only region. Neighborhood measurements are averaged over its actual member Epi centers; no score replication creates extra observations. Endothelial density means supported nuclear objects per observed mm², not an exhaustive true-cell density. Distance means center-to-supported-EC-object distance, not vessel-wall distance. The nearest observed grid boundary provides a conservative censoring check; distances exceeding it remain censored/NA. A region with >20% censored member distances has no formal regional distance. Missing Treg endpoints remain NA rather than zeros or arbitrary maximum distances.

Both radii retain unadjusted rank association and prespecified conditional standardized-rank slopes (log RNA detection, Epi marker balance, observed-area support), plus a vessel-distance-conditioned abundance check. Marker balance is not a measured cellular purity fraction. Highly sparse targets or <50 regions/<12 blocks are descriptive, without forced P values. Spatial400 μm block-pair bootstrap (499) gives95% CIs; restricted-null block-sign wild bootstrap gives exploratory within-section P values. A fixed800 μm block sensitivity checks uncertainty scale. This is single-section spatial support, not independent-patient validation; residual across-block dependence is a limitation.

Continuous endpoints/model purposes form declared BH families; niche associations form their own family; missing endpoints do not acquire fabricated P values. Regions with >=60% of their frozen Epi centers in one niche get a **summary niche** for region-level contrasts, while mixed regions are retained as such. Niche continuous contrasts are conditional rank effects. H50/H10/H05 summaries are prespecified descriptive sensitivities, not alternate primary tests chosen by significance. Report all directions and null/NA outcomes.

## Final bounded audits and interpretation limits

The installed `spacexr:::get_beta_doublet` was actually called on saved native outputs. It sets singlets to first_type=1, keeps both pair weights only for doublet_certain, and returns no reliable complete contribution for uncertain/reject. The initial pair-fit diagnostic had retained a singlet's alternative doublet fit. Raw pair weights remain unchanged; selected-model contributions now reproduce the installed helper exactly, with nonreliable rows explicitly NA. Corrected bin16 detected Epi/collagen co-occurrence is about30%, comparable with cells30.5%; the earlier argument that cells were less mixed is withdrawn. `unit_selection_audited.tsv` records this correction alongside the unchanged pre-association operational cell/regional main branch. No general bin/cell winner is established. Annotation, cell neighborhoods, primary scores and their associations did not change in this reporting audit.

Binary niche contrasts additionally require >=20 regions and >=8 occupied400μm blocks on each comparison side. Final statistical-validity inspection found only one scoreable region in50μm niche3, so its P and interval were withdrawn. This was a validity correction, not K or score reselection; the diagnostic before/after distinction is documented. Both abundance and distance have800μm block sensitivities. A known-fraction covariate sensitivity and one prior-BANKSY-domain/edge-context model address incomplete annotation and regional confounding. The nearest <=8μm native8 bin to an Epi regional centroid supplies only a contextual domain covariate; it is not one-to-one cell/bin identity matching. Domains with <30 analyzed regions are grouped as a small-context nuisance category, not removed from biological results.

A single endothelial-purity sensitivity excludes supported EC objects with >=2 raw Epi or >=2 collagen/Fib markers:204→96. It does not redefine the main annotation/niche. Separate BH families retain all such sensitivity results, not only supportive ones. These checks reduce confidence in a strong mechanistic interpretation even when the distance direction persists. No further threshold/parameter search follows.

`auc_original` in legacy diagnostic columns means the **native random-zero sensitivity**, not the project's original historical primary score. `mp10_historical_auc` / regional `MP10` are historical average-tie scores. `score_eligible` and `association_eligible` must be applied; an unscorable diagnostic number is never an eligible Low observation. The historical formula itself has no random seed; seed124/125 columns compare it with native zero-excluded rankings rather than claim seed variability of the historical method.
