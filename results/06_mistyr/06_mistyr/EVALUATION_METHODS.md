# Module 06: intra-spot predictive dependencies

Only Module 06 is executed. No para/juxta views, radius selection, geometry analysis, communication analysis, AUCell recomputation or signature changes are performed. Inputs remain read-only. The current request authorizes Module 06 despite the Module 00 contract retaining its historical `allowed_modules: [00,01]` scope.

## Literature and actual software

[Wang et al., Molecular Cancer 2025](https://doi.org/10.1186/s12943-025-02377-9), Methods, “Spatial dependencies and colocalization analysis”, reports mistyR 1.10.0, cell2location cell-type estimates, an intra-spot view and median standardized importances. This project uses the accepted bladder sections and its approved major map; it does not reproduce the original renal-cancer data. No positive/negative biological direction is inferred from importance.

The installed release is **mistyR 1.18.0**, Bioconductor RELEASE_3_22, source commit `1401996` (2025-10-29). The archived release tarball and SHA256 identify the actual code. This version differs from the paper and the website vignette (1.10.0). Dependency `distances` and mistyR are installed in `06_mistyr/runtime/Rlib`; existing R libraries are read-only fallback libraries. Neither base R nor the c2l environment was changed.

Official references: [workflow vignette](https://saezlab.github.io/mistyR/articles/mistyR.html), [run_misty](https://saezlab.github.io/mistyR/reference/run_misty.html), [collect_results](https://saezlab.github.io/mistyR/reference/collect_results.html). The archived release R source, rather than website version assumptions, defines the executed behavior.

Actual APIs: `create_initial_view`, `run_misty(..., target.subset, cv.folds=10, cached=FALSE, model.function=audit_rf)`, `collect_results`. `audit_rf` is an audited wrapper around the same `ranger` regression learner used by the package: 100 trees, impurity importance, default floor(sqrt(p)) mtry, minimum node size 5, one thread, fixed seed. It saves the fitted forests and OOB predictions and rejects target self-prediction or a perfect monotone target copy. The wrapper adds no extra predictors. All models have just the intraview.

## A: wang_style_cellcell_intra

All frozen tissue spots with complete nonnegative c2l posterior mean abundance are retained. Approved subtype-to-major sums produce nine non-overlapping major variables. Each major is predicted from the other valid majors; subtypes do not enter this network. Raw unclosed expected-cell abundances are modeled without normalization or log transformation. Original exports are preserved. Constants and insufficient sample sizes receive explicit status, never imputed zeros.

Each forest generates OOB predictions. MISTyR then calibrates these predictions with a linear meta-model and reports ten random meta-fold performance estimates. These are **internal estimates**, not external or spatial validation. Package-written R² values are clipped below at zero. We additionally save unmodified forest OOB predictions, OOB R²/RMSE/MAE, and reconstructed random meta-fold R²/RMSE/MAE before clipping, using the same seed and `caret::createFolds`. Interpretation requires both unclipped mean internal meta R² and forest OOB R² to be positive. No claim of spatial generalization is made for A.

## B: mp10_target_extension

This is a project extension. The target is frozen **raw EpiMP10 Top20 AUCell**, joined exactly by `(section_id, barcode)` from Module 01. Baseline predictors are historical `epi_fraction_gate` and `log1p(nCount)`. The gate is c2l mean Epithelial divided by the sum of all 30 means, threshold >=0.25. RCTD is not substituted. nCount is the raw input X row sum over all frozen features. No fitted transformation is used; log1p is a fixed formula. MP scores are neither standardized nor truncated.

The full model adds all 29 non-epithelial subtype posterior means (including every valid immune/stromal factor). It adds no major sums or epithelial subtype, preventing duplicate major/subtype variables. These predictors are unclosed abundances; they are not a set of proportions summing to one. Other MPs, score ranks, display scores and high/low labels never enter the models.

Both models use exactly the same legacy-eligible complete-case spots, assessed jointly across target, both technical covariates and all TME predictors. Missing values are excluded and counted, never set to zero.

## Fixed spatial block evaluation

For each section separately, coordinates are the true staggered Visium lattice, transformed to `x=array_col/2`, `y=sqrt(3)*array_row/2`. Along the axis with greater tissue extent, the coordinates of eligible complete-case spots are divided into five contiguous quantile bands. Only coordinates and inclusion/missingness flags define bands; target values are not used. Identical stored fold assignments are used by baseline and full models. The initial pilot showed that full-tissue quantiles placed BC15's 167 eligible spots in one band, so the geometry scope was corrected before full execution; no folds were selected using prediction performance. This is not a radius or performance search.

For each held-out band, a fresh ranger forest is trained on the other bands. A linear calibrator is fitted to **training-only OOB predictions** and training targets. The test forest prediction is then passed through this calibrator. Target values in held-out spots are used only for evaluation. Predictor variance filtering is fitted on the training fold. Full-data variable filtering in internal models does not determine outer-fold predictor selection. No target-dependent folds or tuning is performed. At least 100 complete cases per section, 50 training spots and 20 test spots per fold are required. Non-estimable folds are retained in the status table.

Saved `spatial_r2` is pooled out-of-fold `1-SSE/SST`, with SST centered on the evaluation-set mean; `spatial_q2_train_mean` instead compares with the training-fold mean predictor. RMSE/MAE use raw AUCell units. Delta R² is full minus baseline; delta RMSE is baseline minus full. Negative performance and negative increments remain unchanged. Incomplete folds do not receive a full spatial-CV score. MP10 importance is interpreted only when all five folds are evaluated, pooled full R² > 0, and delta R² > 0. This is a descriptive reporting criterion, not a significance test.

These are held-out spatial regions **within a section**, without an exclusion buffer. Autocorrelation across band boundaries can remain; this is not new-patient, new-section, or independent-cohort validation. Spatial covariates are not model predictors. No sections are concatenated for model training or neighborhood construction.

## Importance and direction remain separate

Raw ranger impurity importance is nonnegative predictive contribution, with potential cardinality/correlation biases. It does not encode promotion, inhibition, exclusion, or causality. The intended `collect_results` computation is per-target `scale(raw_importance)` multiplied by `(1 - p_intra_coefficient)`. Therefore standardized importances can be negative: that means below-average relative importance, not a negative biological effect. The coefficient P value is an internal calibration quantity, not an edge-level or causal P value.

**Observed release defect and project correction:** mistyR 1.18.0 writes a five-column coefficient header but six data fields for the single-intra linear meta-model, because an extra NA is prepended to the P-value vector. Consequently the native reader's `p.intra` field is actually the intercept P value; the final serialized field is the true slope P value. This was confirmed independently for every fitted target by reconstructing `lm(observed ~ oob_prediction)` from saved OOB predictions. `native_coefficient_serialization_audit.tsv` records both fields, the reconstructed slope P value and exact native-importance reproduction checks. `correct_importance.R` uses the verified true slope P value for `standardized_importance`, retaining the unmodified API value as `native_standardized_importance`. Native text files and collected RDS objects remain untouched. Dataset medians and figures use the corrected formula. Model fitting, predictions, performance, direction-association tables and reporting flags are unchanged. This is a documented project correction to a release serialization defect, not an unqualified original-paper replication.

Native `collect_results` aggregates by **mean**. Its native results are preserved for audit. The requested dataset summary is separately calculated as the equal-section **median** of the per-section standardized importances. Both all-estimable and performance-qualified medians, with denominators, are provided. Conditional medians may emphasize better-performing sections; all values and selection flags remain available. Standardization failures and structural self-edges remain NA; no missing value is recoded as zero. Here the term standardization refers only to importances, never to MP scores.

Direction is provided separately in `abundance_mp_technical_associations.tsv` as descriptive marginal Spearman correlations. No combined importance-direction score or signed network arrow is generated. Correlations are not spatially calibrated significance tests. Shared counts/technical variation may drive abundance-network edges. Correlated or rare T/NK subtype importances should not be read as specific cell communication. No patient-level inference is performed: the frozen patient column is retained as missing rather than treating section or specimen as patient.

## Outputs and reproducibility

Each section retains model input, models, predictions, counts and variance summaries, predictor exclusion audits, spatial fold metrics, native clipped internal metrics, unclipped internal metrics, branch statuses, importance and association tables. Dataset directories preserve frozen dataset names, including `__UNVERIFIED`. Aggregated figures use the existing project `save_both` function extracted without executing its parent script, with PNG resolution changed to 600 dpi; PDF and thumbnails accompany it. Grey is NA; true zero is black. Heatmap colours for signed standardized importance do not represent biological direction.

The pilot is processed first; full execution starts only after its model calls, exclusions and matching baseline/full test keys pass. A future closure serialization issue found in the initial pilot was repaired by saving audit records per target and explicitly collecting them from disk. Cache reuse requires identical input, model code, parameters and installed package descriptor. Review ZIP excludes raw input tables, forests, posterior matrices and package libraries. No subsequent module is started.
