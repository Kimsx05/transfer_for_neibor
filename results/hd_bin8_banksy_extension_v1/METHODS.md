## Counts, coordinates and QC

All inputs have 18,085 original Ensembl features, with original symbols retained. Native UC_SCC matrix barcodes are joined exactly to `tissue_positions.parquet`. Coordinates use `microns_per_pixel=0.3779763963998723`, explicitly supplied in scalefactors; fullres columns→x and rows→y, y increases down the image. Affine checks against array row/column verify 8 μm spacing and orientation. This is not an estimate from image width/height.

MPBC barcodes are fully checked against `s_002um_ROW_COL-library`: all valid, unique (array,row,col), one library per sample, nonnegative original indices. Aggregation is floor(row/4), floor(col/4), preserving original origin (0,0), never shifting by observed minima. Relative center coordinates are x=8*(col8+0.5), y=8*(row8+0.5); anatomical orientation and H&E relation remain unknown. Each original supplied bin contributes exactly once. Per-gene and total counts are checked before/after aggregation. No 2 μm UMI filter is applied first.

MPBC records supplied positions, supplied zero-expression positions and unprovided positions separately. Sixteen positions is the nominal 4×4 footprint. The full physical array boundary is not independently supplied: `expected_array_clipped_positions` stays NA; a partially supplied terminal bin is not automatically labelled a known array-edge truncation. The observed maximum index does not establish array geometry. `nominal_4x4_supplied_fraction` is explicitly nominal, not a verified clipped-array coverage fraction.

UC_SCC QC: supplied, original in_tissue=1, nCount>5. MPBC QC: supplied and nCount>5 only; `in_tissue_original=NA` remains unknown. A filtered filename or expression threshold is not a tissue mask. All input bins retain QC flags/reasons in compressed metadata. Input raw H5 remains available; MPBC has one compressed sparse 8 μm H5, not a duplicate 2 μm matrix. Normalized full-gene data is persisted once per new section. No additional feature/mitochondrial/small-cluster filter.

Information strata are <20,20–99,100–499,≥500 detected genes. Cross-section proportions separately use all analysis bins and both-reference-evaluable bins, with UMI-weighted counterparts. MPBC denominators lack confirmed tissue selection and are always supplementary. These histologically different cases are not matched technical replicates.

## Model and neighborhood control

Each new section uses the same full QC set, once-frozen 3,000 HVGs, seed123, 30 PCs, own/neighborhood mean features, no AGF. SNN k=20, Euclidean Annoy50trees, prune=1/15; Louvain algorithm1, resolution0.5, 10 starts/10 iterations. Standard Seurat singleton handling is retained consistently; no small non-singleton cluster deletion. UMAP: cosine,30 neighbors,min.dist0.3,spread1,200epochs,8workers. UMAP diagnostics do not override original RNA/physical spatial evidence. No resolution/feature/neighborhood sweep.

Geometry grouping uses 8-connected supplied grids before count QC, original in_tissue for UC_SCC; MPBC groups are input-support components, not validated tissue pieces. No cross-array/section/reference-defined edges. Neighbor search uses full valid bins, not sketch. Global scaling is shared across all components. Actual neighbor counts and distances are saved; small components retain all available neighbors, singleton fallback is explicit. Any geometry restriction adopted after reviewing long edges is recorded in `geometry_decision.md`, not hidden as a package default.

Runtime limits: maximum8 numerical threads and BLAS1, UMAP8workers, sequential sections/models, nice10, virtual-memory cap180GiB, total below48CPU/200GB. Single-thread input/QC preparation, targeted old-result summaries and plotting are light daytime work. Heavy normalization/model/SingleR pipeline is supervised in Asia/Shanghai 23:00–07:00; active process groups pause outside that window and resume in the next one. A waiting or paused process is not reported as completed. `logs/night_status.json` records current scheduler state; no external scheduler/task message or data upload is used.

## References and marker evidence

References remain frozen at `../hd_annotation_diagnosis_singler_v1/reference`: BLCA44,896 cells, nine major classes, Wilcoxon training with aggregation; existing HPCA ten native labels mapped to six major classes, classic training. No new sampling/retraining is silently substituted. BLCA uses Ensembl; HPCA temporary raw counts are summed for duplicate symbols before LogNormalize. Full query genes are checked against trained test genes. Constant selected-gene profiles retain IDs with an explicit non-evaluable status. Scores are correlations, `delta.next` is the native output; globally pruned labels are candidates, not calibrated confidence. Per-bin labels are not replaced by cluster-level classification.

Four coarse fields remain reference-specific: Epithelial, Mesenchymal(Fibroblast+Mural), Endothelial, Immune(T/NK/Myeloid/B/Plasma/Mast), Unknown. HPCA lacks independent Mural/Mast/Plasma coverage. No consensus or spatial voting fills missing identities.

Targeted statistics use original counts and LogNormalize; detected fraction, average log expression, mean linear normalized expression and log2(1+mean)-difference versus other bins are separate quantities. No BANKSY mean or scaled expression is used. Per-bin multi-gene co-detection does not establish doublets, multicellular proportions, EMT or malignancy.

All-gene descriptive cluster markers retain prior effect/detection ranking, without spatial-bin P values interpreted as biological replication. Original region names remain intact. `ext_` fields and supplementary explanations do not overwrite them; expanded panels do not silently redefine only D1/new sections. Cluster-level SingleR is run on lambda0.2 and0.8 original-expression sums and retains disagreements.

## ROI, figures and incremental loading

Old fixed ROI ranges/transforms are reused. D1 adds a 256 μm agreement control selected by the largest pre-existing BLCA/HPCA epithelial-agreement count; this is a reference comparator, not histological purity. New-section four fixed256μm windows are chosen before predictions/BANKSY from low/median/high nFeature window quantiles and sparse input support (minimum128 valid bins/window). Exact rules and ranges are in `fixed_rois.tsv`; expression-support edges are not labelled anatomical edges. UC_SCC hires supplies only coarse morphology; MPBC plots are pure relative-coordinate plots.

Installed `jins-routine-plotting` theme/palette/export is reused. Spatial/multipanel comparisons do not match a single supplied template; user-requested raster dense layers and matched panels take precedence over generic single-vector-plot defaults. White Arial12pt; PNG300dpi; PDF vector text/legends with raster points/H&E. Legend-bearing plots retain full, panel-only, legend-only PDFs; archive includes only selected PNGs to limit size. Same coarse palette across sections/references. No smoothing for marker proof.

`code/load_result.R::load_extension(root,section)` attaches old supplements or reconstructs each new analysis object from one raw-count source, one normalized sparse layer, metadata and three incremental PCA/UMAP bundles. Source paths resolve relative to the output tree. No full RDS/h5ad copies are required. Actual final readback validates IDs, counts/QC accounting, coordinates, all branch embeddings and unknown tissue status and produces a re-read counts plot. Stage markers and source/HVG/parameter identity guard cache reuse. Large temporary matrices may be removed only after validation; frozen inputs, code, parameters and required outputs remain.

A single bounded descriptive information-standardization is prepared for the three tissue-verified sections, because input QC already shows materially different detection distributions. Once UC_SCC predictions exist, rates are compared using common 20-gene nFeature strata (>=1,000 pooled), with weights proportional to the minimum observed stratum count across Cervilla/D1/UC_SCC. No expression is downsampled, no labels/counts change and no model is rerun. It supplements the requested four-band tables; standardized fractions are weighted descriptive rates, not raw cell proportions or accuracy. MPBC remains outside this primary tissue-verified comparison. Fine stratification still does not match histological composition or eliminate all technical differences.

## Final review and focused geometry/plot corrections

The input-edge distance inherited from the earlier code omitted explicit zero padding outside the grid. This can underestimate boundary membership when supplied support fills a rectangular array. The extension now pads unsupported exterior positions before the Euclidean distance transform. This is distance to supplied support, not a known physical array or anatomical tissue boundary. New-section summaries use the corrected distance; old formal files remain unchanged and old loaded objects receive `ext_input_edge_distance_um`. The first-change counts are retained in `tables/input_edge_distance_correction.tsv`. No spatial neighbor, QC flag, model, count or cluster changed. Corrections affect edge16 membership in1,100 Cervilla,550 D1,4,850 UC_SCC,5,976 MPBC1 and2,783 MPBC2 bins; do not infer an anatomical cause from the former boundary statistic.

Regional review is a separate increment (`ext_recommended_branch`, `ext_recommended_region`, `ext_region_review_note`) applied by the same ID-based code to all five sections. Original type and region fields remain intact. The small explicit `reviewed_region_notes.tsv` records original-RNA evidence for D1 keratin/collagen regions, UC immune/stromal and vascular composites, and an MPBC1 vascular-associated composite. These are targeted descriptive reviews, not a new classifier or a rule forcing all cluster members to one cell identity. Marker detection, relative enrichment, regional predominance and actual multicellular admixture remain distinct claims.

ROI graphics explicitly retain each frozen physical window, including blank unprovided positions; they no longer auto-zoom a sparsely occupied strip. A64μm scale bar accompanies the coordinate axes. UC_SCC's four existing hires-image crops are displayed at those same physical coordinates (panel identity table supplied); no MPBC image is invented. A long region legend was wrapped and the H&E overlay made less opaque; these edits change presentation only.
