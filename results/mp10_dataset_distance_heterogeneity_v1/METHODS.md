# Actual analysis specification

Frozen section/Epi/P95/candidate definitions and scores are read from existing summary tables only. No point-level cache, SCT/c2l object or expression matrix is restored. Known repeat sections are combined within their existing analysis_unit_uid; correlations use equal-weight Fisher z and paired delta uses the mean of section-level paired delta (never a difference of separately pooled correlations). Section-only records lacking analysis_unit_uid remain descriptive; combinations including these records do not acquire biological-replicate P values.

Canonical programmes are determined by exact accepted gene membership. Full and noMP10 programmes occupy separate matrices. Identical Budden/Reactome cholesterol membership is represented once, preferentially using the explicitly requested Budden programme and its actual score. Puram Top100 replaces Top30 only in a sensitivity matrix. Original endpoint statistics and P/q meanings remain available at the indexed source; beta/curve P or CI are not reassigned to r.

All nonempty dataset subsets supported by each endpoint are enumerated, including singleton datasets. Conditional means weight datasets equally after unit means. Conditional unit-level uncertainty uses between-unit variance within each selected dataset, with a Welch-Satterthwaite t interval. This is distinct from a t test across selected dataset means (only >=3 datasets). Both have their own within-combination and across-search BH. These are exploratory selected-subset results, not independent replication. Conditional unit uncertainty does not replace missing point-level spatial errors.

Candidate C1/C2 use n>=10 (both groups for C2), with n>=30 sensitivity. Other endpoints retain their original populations and applicable n, without borrowing the P95 rule. Exact full/common/common_0_1000 ranges and score algorithms remain separate. C2 full_range remains descriptive. Zero/center distances remain in all reused effects.

For heterogeneity, correlations are Fisher-transformed then column standardized. Signed delta/distance effects are column standardized without inappropriate atanh. Composition is Hellinger transformed and centered without per-component SD scaling. Features require >=80% observed units and >=50% within each included dataset. Sporadic missing values use the feature median; entire missing datasets are not imputed. Samples are not selected by effect direction. Units with no information on retained features cannot be ordinated and are counted explicitly. PC1/PC2 are fixed; signs align to a whole-input reference loading. Ward-Euclidean clustering examines K=2..min(6,floor(n/3)); silhouette is descriptive. Rare 1–2-unit groups do not constitute robust types. Five prespecified input examples undergo 100 unit-subset/feature-perturbation runs, dataset leaveout, scale and k-means comparisons. Only summary stability is saved.

The ecological exposure is PC1/PC2 of all-Epi formal R12 composition, derived without any distance outcome. Unit-level outcomes are B3 Epi/tissue r, C1 r, paired C2 delta and C4 r. Dataset fixed effects distinguish within-dataset association from between-dataset ecological means. HC3 intervals treat existing biological analysis units as replicates. A conditional spatial-SE-weighted sensitivity is added where prior spatial uncertainty exists, with residual between-unit variance in the denominator. Dataset leaveout and full/noMP10, score/range/partial comparisons are internal sensitivity, not independent validation. Normal specimens are retained in the input index but excluded from tumour ordination/inference.

Plots follow jins-routine-plotting Arial/white/vector-PDF/300-dpi-PNG and separate legends, with custom PCA/forest/heatmap code because these forms have no exact installed template. No figure-top summary titles. Frozen R12 palettes are reused. No per-combination plots, models or bootstrap arrays are retained.

The n>=30 candidate sensitivity is fixed to the cross-section comparable common_support_0_1000 raw C1/C2 endpoint (both score methods, all full/noMP10 programmes). Alternate distance ranges and partial C1 are retained at n>=10; sensitivities are not fully crossed. Combination output is stored to four significant digits to meet the storage budget; calculations use double precision.

C1 raw-r spatial Fisher-z SE is reused directly. C2 delta SE and C4 raw-r Fisher-z SE, where only prior joint/interval endpoints are available, use interval-width/3.919928 approximations for the optional weighting sensitivity, explicitly conditional on the previous spatial result. No raw-r SE is assigned to partial r. C4 additionally reports a total-Epi n>=20 summary sensitivity because n=3 nearly perfect correlations can dominate Fisher-z means; this is not a change to frozen Epi or a P95 count filter.

Combination BH families are module × signature status × score method × statistic × distance range × minimum-count rule. Within-combination BH covers all available candidate/program endpoints in that family; across-search BH additionally covers every enumerated dataset subset in the same family. Conditional and dataset-replicate P values are corrected separately. Ecology additionally reports BH across its entire 29,664-model scan. Fisher-z calculations clip r only for numerical transformation at ±0.999999; original r values remain in the input. The C4 sparse-count sensitivity explicitly examines this issue.
